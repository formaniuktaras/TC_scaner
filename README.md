# TC_scaner

Лаунчер для Total Commander, який додає кнопку **«Сканувати»** з меню типів документів і автогенерацією назв файлів за шаблонами.

## Що вже реалізовано

- Вікно вибору: що саме сканувати (ВВЗВ, ВВМ, ЄАС, АС, АТС/Наказ, витяги тощо).
- Автоматичний розбір поточної папки:
  - дата справи (`10.05.22`),
  - номер епізоду (`1`),
  - список підрозділів із суфікса (`РС+ЗББР+СЗ+ІС+ВТ`),
  - секція матеріалів (`01` з `01_Матеріали ЄА`).
- Формування імені файлу за шаблоном документа.
- Вибір підрозділу (наприклад `СЗ`, `РС`, `ІС`, ...).
- Окремі налаштування в `scanner_config.json`:
  - список типів документів,
  - коди,
  - шаблони назв,
  - команда запуску сканера.
- У текстових полях доступні зручні інструменти редагування:
  - контекстне меню по правому кліку (вирізати/копіювати/вставити/виділити все/очистити),
  - гарячі клавіші `Ctrl+A`, `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Shift+Insert`, `Ctrl+Insert`,
  - багаторядкове поле для JSON у вікні налаштувань з форматованим відображенням.
- Запуск сканування без `shell=True` (без зайвого `cmd.exe` із боку нашого виклику).
- Чесна валідація результату сканування:
  - успіх показується лише якщо очікуваний файл реально з’явився за `output_path`,
  - файл має бути ненульового розміру,
  - розмір файлу має стабілізуватися щонайменше на 2 послідовних перевірках (polling), що важливо для мережевих папок.
- Діагностичний лог `tc_scanner.log` поруч зі скриптом (команда, return code, stdout/stderr, стан файлу).

## Приклад вашого кейсу

Для папки:

`22005_10.05.22_1_3єб_9єр_РС+ЗББР+СЗ+ІС+ВТ/1.ЄА/01_Матеріали ЄА`

генеруються, зокрема:

- `006_01_витяг з книги втрат_10.05.22_1_СЗ`
- `003_Відомість залишкової вартості_10.05.22_1_СЗ`

## Швидкий старт (Windows)

1. Налаштуйте Python 3.10+.
2. Відкрийте `scanner_config.json` і заповніть `scan_command`, наприклад:

```json
"scan_command": "naps2.console --profile \"Default\" --output \"{output_path}\""
```

> Важливо: команда тепер запускається **без shell=True**, тому використовуйте звичайні аргументи програми. Конструкції `|`, `&&`, `>`, `<` (shell-синтаксис) не підтримуються.
>
> Також команда **обов'язково** має містити `{output_path}` і реально створювати файл за цим шляхом (синхронно або майже синхронно). Якщо зовнішня програма збереже файл в іншу папку або проігнорує `{output_path}`, лаунчер покаже помилку, а не фальшивий успіх.

3. Запуск вручну з абсолютним шляхом до скрипта:

```powershell
python "C:\TC_scaner\tc_scanner_launcher.py" "C:\TC_scaner"
```

> Помилка `can't open file 'C:\Users\...\tc_scanner_launcher.py'` означає, що ви запускали команду не з тієї папки і без абсолютного шляху до скрипта.

## Рекомендоване підключення до Total Commander (без чорного вікна)

Використовуйте **silent launcher** `launch_tc_scanner_silent.vbs`.

- **Command**: `wscript.exe`
- **Parameters**: `"C:\TC_scaner\launch_tc_scanner_silent.vbs" "%P"`
- **Start path**: `C:\TC_scaner`

Що це дає:
- під час запуску з кнопки TC відкривається лише GUI-вікно `TC Scanner`;
- додаткове консольне вікно `cmd.exe` від wrapper не відкривається;
- якщо Python launcher не знайдено, користувач отримує `MsgBox` (а не консольний текст).

## Legacy wrapper

`launch_tc_scanner.cmd` залишений для сумісності, але він може показувати консольне вікно, бо `cmd`-файл у Windows запускається через консольну підсистему.

## Налаштування шаблонів

`scanner_config.json` → `doc_types[]`:

- `label`: назва документа в меню,
- `code`: цифровий код префікса,
- `template`: формат імені.

Підтримувані плейсхолдери:

- `{code}`
- `{label}`
- `{date}`
- `{episode}`
- `{section}`
- `{tag}`

## Тести

```bash
python -m pytest -q
```

Тести перевіряють:

- розбір структури папок,
- генерацію назв у ваших прикладах.
- службову логіку сканування:
  - кейс, коли процес завершився успішно, але файл не створено,
  - появу файлу із затримкою,
  - успішне виявлення вже створеного файлу з ненульовим розміром.
