# TC_scaner

Невеликий Windows-лаунчер на Tkinter для запуску сканування з **Total Commander** з автоматичною генерацією назви PDF-файлу з контексту поточної папки.

## Що робить інструмент

- запускається з кнопки в Total Commander;
- показує список типів документів;
- розбирає поточний шлях і витягує:
  - `date` (дата),
  - `episode` (номер епізоду),
  - `section` (секція, наприклад `01`),
  - `tags` (теги/підрозділи, наприклад `РС+СЗ+ІС`);
- формує назву файлу за шаблоном документа;
- дає можливість вручну змінити ім'я (з санітизацією);
- показує прев'ю повного шляху;
- запускає зовнішню команду сканування через шаблон `{output_path}`;
- обробляє дублікат імені перед скануванням.

## Запуск з Total Commander

Залишайте wrapper:

- `Command`: `C:\TC_scaner\launch_tc_scanner.cmd`
- `Parameters`: `"%P"`
- `Start path`: `C:\TC_scaner`

`launch_tc_scanner.cmd` знаходить `tc_scanner_launcher.py` поруч і запускає через `py -3` або `python`.

## Налаштування `scan_command`

У `scanner_config.json` вкажіть зовнішню команду сканера.

Приклад:

```json
"scan_command": "naps2.console --profile \"Default\" --output \"{output_path}\""
```

> Важливо: у команді обов'язково має бути `{output_path}`.

## Як працює генерація назв

Кожен `doc_type` має `template`. Дозволені плейсхолдери:

- `{code}`
- `{label}`
- `{date}`
- `{episode}`
- `{section}`
- `{tag}`

Плейсхолдери валідуються у вікні налаштувань. Якщо знайдено невідомий плейсхолдер — збереження блокується.

### Реальний приклад

Для папки:

`22005_10.05.22_1_3єб_9єр_РС+ЗББР+СЗ+ІС+ВТ/1.ЄА/01_Матеріали ЄА`

контекст:

- `date = 10.05.22`
- `episode = 1`
- `section = 01`
- `tags = [РС, ЗББР, СЗ, ІС, ВТ]`

приклади назв:

- `006_01_витяг з книги втрат_10.05.22_1_СЗ`
- `003_Відомість залишкової вартості_10.05.22_1_СЗ`

## Дублікат файлу

Якщо цільовий файл вже існує, лаунчер покаже вибір:

- **Скасувати**;
- **Перезаписати**;
- **Створити копію** (автонумерація `ім'я (2).pdf`, `ім'я (3).pdf`, ...).

## Типові проблеми структури папок

- не знайдено `date/episode` → шаблони, що залежать від них, блокують сканування;
- не знайдено `section` → блокуються шаблони з `{section}`;
- не знайдено `tags` → блокуються шаблони з `{tag}`;
- у UI завжди видно розпізнаний контекст і попередження, щоб помилку було видно до запуску сканування.

## Тести

```bash
python -m pytest -q
```

Тести покривають розбір контексту, генерацію імені, валідацію шаблонів, нестачу даних та генерацію копії при конфлікті імен.
